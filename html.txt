Ques 2. What is layout?

Ans = A layout is a way elements are arranged and organized on a web page.
(such as : Header , Navigation , Content , Sidebar , Footer.)

Ques 3. What do you know about flex layout?

Ans = Flex layout (flexbox) is a one dimensional CSS layout system used to arrange items in a row or a column.
Advantages : a) Easy allignment of elements.
b) Responsive designs without complex CSS.
common properties : display , flex - direction , justify contents , align items etc.

Ques 4. What is the need of grid layout?

Ans = Grid layout is used to arrange web page elements in rows and columns .
It is ideal for creating complex and responsive web layouts.
